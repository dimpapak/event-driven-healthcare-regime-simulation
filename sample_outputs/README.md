# Sample Outputs

This directory contains representative outputs generated by the Event-Driven Healthcare Regime Simulation framework.

Generated files include:

- event_log_example.csv
- timeline_example.csv
- results_summary.csv

and publication figures:

- fig1_timeline.png
- fig2_heatmap_tover.png
- fig3_recovery_vs_tau.png

These outputs demonstrate overload emergence, regime transitions,
policy response delays, and recovery dynamics.
